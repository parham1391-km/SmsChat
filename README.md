# SmsChat — پروژه چت مبتنی بر SMS واقعی (اندروید)

این پروژه یک اپ اندروید است که به‌جای اینترنت، از شبکه پیامکی واقعی اپراتور استفاده می‌کند.
تمام کدهای لازم (ارسال، دریافت، دیتابیس، رابط چت) نوشته شده است.

## ساختار پروژه
```
SmsChat/
├── app/src/main/java/com/example/smschat/
│   ├── MainActivity.kt        ← لیست مکالمات + گرفتن مجوزها
│   ├── ChatActivity.kt        ← صفحه یک مکالمه
│   ├── SmsSender.kt           ← ارسال پیامک واقعی
│   ├── SmsReceiver.kt         ← دریافت پیامک ورودی
│   ├── ConversationAdapter.kt
│   ├── MessageAdapter.kt
│   └── data/
│       ├── Message.kt         ← مدل داده Room
│       ├── MessageDao.kt
│       └── AppDatabase.kt
├── app/src/main/res/layout/   ← تمام لایه‌های XML
└── app/src/main/AndroidManifest.xml
```

## مراحلی که باید خودت روی گوشی/سیستم انجام بدی

### ۱. باز کردن پروژه
1. Android Studio (نسخه جدید، مثلاً Koala یا بالاتر) را نصب کن.
2. `File > Open` و پوشه `SmsChat` را انتخاب کن.
3. صبر کن Gradle Sync تمام شود (اینترنت لازم دارد چون وابستگی‌ها دانلود می‌شوند).

### ۲. اتصال گوشی واقعی
- چون شبیه‌ساز اندروید SIM/آنتن واقعی ندارد، **باید از یک گوشی اندروید واقعی** استفاده کنی.
- USB Debugging را در گوشی فعال کن (Settings > About phone > روی Build number چند بار بزن > Developer options > USB debugging).
- گوشی را با کابل وصل کن و در Android Studio دکمه Run (▶) را بزن.

### ۳. تأیید مجوزها (هنگام اولین اجرا)
اپ در startup خودش درخواست مجوز `SEND_SMS`, `RECEIVE_SMS`, `READ_SMS` را نشان می‌دهد —
فقط کافیست روی «Allow» بزنی.

### ۴. انتخاب SmsChat به‌عنوان اپ پیش‌فرض پیامک
بلافاصله بعد از تأیید مجوزها، یک دیالوگ سیستمی می‌آید که می‌پرسد
«SmsChat را اپ پیش‌فرض SMS کنم؟» — تأیید کن.
(بدون این مرحله، `SmsReceiver` پیامک ورودی را دریافت نمی‌کند، چون فقط اپ پیش‌فرض
اجازه‌ی broadcast با اکشن `SMS_DELIVER` را می‌گیرد.)

اگر بعداً خواستی این را دستی از تنظیمات هم بررسی/عوض کنی:
`Settings > Apps > Default apps > SMS app`

### ۵. تست عملی
- از یک گوشی دیگر (یا SIM دیگر) به شماره گوشی تستت پیامک بفرست → باید در لیست مکالمات
  SmsChat ظاهر شود.
- از داخل اپ یک شماره وارد کن و پیام بفرست → باید به‌صورت SMS واقعی برسد.

## قابلیت‌های جدید: گروه و حذف پیام

### گروه
- روی دکمه «گروه جدید» در صفحه اصلی بزن، یک نام و لیست شماره‌ها (با کاما یا خط جدید
  جدا شده) وارد کن.
- وقتی توی چت گروه پیام می‌فرستی، اپ به‌صورت جداگانه برای **هر عضو یک SMS واقعی**
  می‌فرستد، ولی در اپ همه در یک thread واحد دیده می‌شوند.
- **محدودیت مهم:** SMS استاندارد مفهوم «گروه یکپارچه» ندارد (برخلاف واتساپ/تلگرام).
  وقتی یکی از اعضا جواب می‌دهد، پیامکش از شماره خودش می‌آید؛ اپ این شماره را با
  اعضای گروه‌های ذخیره‌شده مقایسه می‌کند و اگر عضو یکی از گروه‌ها بود (best-effort،
  فقط اولین گروه در صورت عضویت در چند گروه)، پیام را در thread همان گروه نشان
  می‌دهد. این یک شبیه‌سازی محلی است، نه یک ویژگی واقعی شبکه پیامکی.

### حذف پیام
- برای حذف یک پیام تکی: روی حباب پیام در صفحه چت **فشار طولانی (long-press)** بده.
- برای حذف کل یک مکالمه یا گروه: در لیست مکالمات صفحه اصلی، ردیف مربوطه را
  **به چپ یا راست بکش (swipe)**.
- توجه: این حذف فقط تاریخچه‌ی محلی داخل اپ را پاک می‌کند؛ چون پیامک از قبل واقعاً
  از طریق شبکه اپراتور ارسال/دریافت شده، امکان پاک کردنش از شبکه یا از گوشی طرف
  مقابل وجود ندارد — دقیقاً مثل اپ پیش‌فرض Messages خود اندروید.

### نکته درباره schema دیتابیس
چون Entity جدید (گروه‌ها) اضافه شده، نسخه دیتابیس بالا رفته و به‌صورت
`fallbackToDestructiveMigration()` تنظیم شده — یعنی اگر قبلاً نسخه قبلی اپ را نصب
کرده بودی، هنگام آپدیت، دیتابیس قدیمی (تاریخچه چت‌ها) پاک می‌شود. برای تست تازه
مشکلی نیست؛ برای یک اپ واقعی باید Room Migration درست بنویسی.

## نکات مهم / محدودیت‌های شناخته‌شده
- این پروژه فقط **اندروید** را پوشش می‌دهد؛ اپل اجازه SMS برنامه‌نویسی‌شده به اپ‌های
  شخص‌ثالث نمی‌دهد.
- برای این‌که گوگل پلی رسماً یک اپ را به‌عنوان «Default SMS app» بپذیرد (اگر روزی
  خواستی در Play Store منتشرش کنی)، معمولاً باید کامپوننت‌های بیشتری هم اضافه شوند
  (مثل سرویس `RESPOND_VIA_MESSAGE` و مدیریت MMS). برای استفاده شخصی/تست روی گوشی
  خودت لازم نیست.
- هزینه هر پیامک طبق تعرفه اپراتور SIM فرستنده محاسبه می‌شود.
- اگر گوشی گیرنده هم SmsChat نصب داشته باشد بهتر است (چون UI چت‌مانند می‌بیند)، ولی
  حتی اگر نداشته باشد، باز هم پیامک را به‌صورت SMS معمولی در اپ پیش‌فرض خودش می‌بیند —
  چون در سطح شبکه، این‌ها پیامک‌های کاملاً استانداردند.
